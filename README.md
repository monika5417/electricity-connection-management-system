# Electricity Connection Management System

## 📌 Project Overview

Electricity Connection Management System is a Spring Boot based backend application developed to manage new electricity connection requests.

The application provides REST APIs for managing consumers, electricity connections, document verification and connection approval workflow.

---

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Oracle Database
- Maven
- Lombok
- REST APIs

---

## Modules

- Consumer Management
- Connection Management
- Approval Workflow
- Payment Details
- Document Verification
- Dashboard
